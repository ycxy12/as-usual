# 日常集：第四阶段「我的」设计

状态：用户确认继续实现，2026-09-20。

## 范围

「我的」负责全局能力：简洁数据概览、分类管理、标签管理、数据管理和设置。继续使用微信身份隔离的服务端数据，不增加账号页面。

## 数据概览

展示本月记录次数、物品数量、衣服数量、本月车辆成本、本月居住成本、去过的餐厅和地点。记录次数包含当月碎片、车辆、居住和人情往来条数。页面保持摘要式布局，不做复杂 Dashboard。

## 分类管理

- 支持个人物品、衣柜、车辆费用、居住费用、餐厅菜系和地点类型六个模块。
- 每个用户首次访问时获得当前默认分类，可新增、改名、删除。
- 改名会在同一事务内同步该用户已有业务数据；删除最后一个分类或仍被业务数据使用的分类会被阻止。
- 业务新增/编辑接口按当前用户的分类配置校验；相关小程序表单与筛选页动态读取分类，并保留内置分类作为网络失败时的回退。

## 标签管理

标签页聚合碎片、物品、衣物、餐厅、地点中实际使用的标签，以及用户单独创建的标签。支持搜索、新增、改名和删除。改名与删除同步所有绑定关系；同一条业务数据已有目标标签时自动合并，不产生重复。

## 数据管理

展示各模块数据数量、图片数量和存储说明。清空操作需要两次确认，其中第二次输入“清空”；服务端仅清除当前微信用户的业务数据、分类、标签和私有图片，保留登录身份。清空后不可恢复。

## 设置与说明

设置页展示外观原则、隐私说明、版本号和关于信息。外观沿用全局暖白、低饱和绿色与系统字号，避免在第四阶段引入一套未覆盖全页面的主题切换。隐私说明明确微信 openid 只在服务端用于隔离数据，图片下载需登录。

## 验收

1. 概览数字按当前用户和月份计算，用户之间互不影响。
2. 分类增改删规则正确，改名同步数据，所有相关表单使用动态分类。
3. 标签聚合、搜索、新增、改名和删除覆盖五类支持标签的业务。
4. 清空接口只删除当前用户数据及图片，其他用户数据不受影响。
5. Maven 测试、格式检查、TypeScript 检查和页面结构检查通过。
